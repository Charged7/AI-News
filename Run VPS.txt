алгоритм, як дійти до команд налаштування VPS через термінал з самого відкриття терміналу після перезавантаження Windows.


1. Відкрити Термінал
Після перезавантаження Windows відкрий:
Start -> PowerShell
або:
Start -> Windows Terminal
Можна відкривати з будь-якої папки. Для SSH це не важливо.


2. Підключитися До VPS
У Windows PowerShell введи:
ssh newsbot@167.172.102.107
Якщо треба зайти як адміністратор сервера:
ssh root@167.172.102.107
Для звичайної роботи з ботом краще:
ssh newsbot@167.172.102.107
Після успішного входу маєш побачити:
newsbot@ubuntu-s-1vcpu-512mb-10gb-fra1:~$
Це означає, що ти вже на сервері Ubuntu.


3. Перейти В Папку Проєкту
На сервері введи:
cd ~/apps/charged-news
Перевірити, що ти в правильній папці:
pwd
Очікувано:
/home/newsbot/apps/charged-news


4. Активувати Python-Середовище
У папці проєкту:
source .venv/bin/activate
Після цього prompt має стати приблизно таким:
(.venv) newsbot@ubuntu-s-1vcpu-512mb-10gb-fra1:~/apps/charged-news$
Це означає, що Python-залежності бота доступні.


5. Основні Команди Для Бота
Перевірити, коли наступний автоматичний запуск:
systemctl list-timers --all | grep charged
Перевірити timer:
systemctl status charged-news-bot.timer
Вийти зі статусу:
q
Запустити бота вручну:
sudo systemctl start charged-news-bot
Подивитися статус останнього запуску:
systemctl status charged-news-bot
Подивитися останні логи:
journalctl -u charged-news-bot -n 100 --no-pager
Дивитися логи наживо:
journalctl -u charged-news-bot -f
Вийти з live logs:
Ctrl + C


6. Якщо Треба Оновити Код З GitHub
У папці проєкту:
git pull
Після оновлення залежностей, якщо змінювався requirements.txt:
source .venv/bin/activate
pip install -r requirements.txt
Потім ручний тест:
python main.py


7. Якщо Треба Редагувати .env
nano .env
Зберегти в nano:
Ctrl + O
Enter
Ctrl + X
Вміст .env нікому не надсилати, бо там токени.


8. Якщо Треба Перезапустити Автоматизацію
Для oneshot-сервісу “restart” майже не потрібен, бо він сам завершується. Ручний запуск:
sudo systemctl start charged-news-bot
Перезапустити timer:
sudo systemctl restart charged-news-bot.timer
Перевірити:
systemctl list-timers --all | grep charged


9. Вийти З VPS
Коли завершив роботу:
exit
Після цього ти повернешся у Windows PowerShell:
PS C:\Windows\system32>


10. Найкоротший Щоденний Маршрут
ssh newsbot@167.172.102.107
cd ~/apps/charged-news
source .venv/bin/activate
systemctl list-timers --all | grep charged
journalctl -u charged-news-bot -n 50 --no-pager
Це базовий шлях: зайти на сервер, перейти в проєкт, активувати середовище, перевірити timer і логи.
